# ClubSimulation

# The assignment entails producing a Java 
  simulation of a club, ensuring that it follows 
  defined behavioral rules

## Usage
# 1.Using the terminal/command prompt, change directory until you are in a folder where the source,bin and makefile is located
# 2. Type command "make all"
# 3. if you want to run the program type in command "make run"
# 4. After entering that command,the ClubSimulation visual should come up
# 5. Press Start button to start simulation
# 6. Press Pause to pause the simulation.If Paused,you can click the Resume button to resume the simulation.
# 7. If you want to quit the program,press the quit program.
